# KPI definitions

| KPI | Definition | Why it matters |
|---|---|---|
| Average installed-base age (years) | Mean of (reference date - install date) over all machines | Shows how much of the base is approaching end of life and modernisation potential. |
| % out of warranty | Machines with warranty end before the reference date / all machines | Out-of-warranty machines are where service contracts and spare-part sales can happen. |
| Failures per 100 machines (last 12 months) | Failures in the last 12 months x 100 / number of machines | Normalises reliability across fleets of different size so customers and models are comparable. |
| Average downtime per failure (hours) | Mean downtime_hours over all failures | Measures how costly each failure is for the customer, which drives service-level discussions. |
| Spare-part revenue per machine (EUR) | Total spare-part order value / number of machines | Shows how much aftermarket value each installed machine generates. |
| Data-quality score (%) | Records passing all quality rules / all records checked (raw layer) | Tells everyone how far the reports can be trusted and whether the data is getting better. |

Reference date of the synthetic data: 2026-11-01. All values come from the clean layer, except the data-quality score, which is measured on the raw layer.
